ANIMATION

CSS animation makes an element move or change automatically over time.For example A box moving from left to right , a button changing color ,an image rotating and a text fades in.

CSS animations always need two parts.

1.@Keyframes
This tells CSS what should happen.

2.@animation
This tells CSS how the animation should run

Basic syntax of css animation syntax and keyframe syntax

CSS Syntax

selector { animation-name: name;
animation-duration: time;
animation-iteration-count: number;
animation-timing-function: ease | linear | etc;
animation-delay: time;
animation-direction: normal | reverse | alternate; }

Keyframes Syntax

@keyframes animation-name{
from { /* CSS properties */ }
to{ /* CSS properties */ }
}
